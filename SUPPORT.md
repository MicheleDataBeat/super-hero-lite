# Support

## Current availability

General one-to-one usage support is not currently offered. The public
contribution forms provide the available ordinary channels:

- Use the [bug report form](https://github.com/MicheleDataBeat/super-hero-lite/issues/new?template=bug_report.yml)
  for a reproducible defect. Include the Host Distribution, the version from
  [VERSION](VERSION), and the redacted output of `./validate.sh`. Redacted
  means: no credentials, tokens, private keys or unnecessary personal data.
- Use the [feature request form](https://github.com/MicheleDataBeat/super-hero-lite/issues/new?template=feature_request.yml)
  for a focused improvement and its Host impact.

Support is not the right channel for a suspected vulnerability: follow
[Security](SECURITY.md) and never disclose a vulnerability in public Issues.
It is also not the conduct-reporting channel; use the private address in the
[Code of Conduct](CODE_OF_CONDUCT.md).

For a material product or workflow decision, use the process in
[Governance](GOVERNANCE.md). The limited ordinary channels above do not create
a private support commitment.
